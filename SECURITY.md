# Sicherheitspolitik

*English: please report vulnerabilities privately via GitHub's "Report a vulnerability" button, never in a public issue.*

## Unterstützte Version

Unterstützt wird ausschließlich der jeweils neueste Stand von `master`.

## Sicherheitslücke melden

1. Bitte über **"Report a vulnerability"** im Reiter *Security* dieses Repos melden
   (Private Vulnerability Reporting):
   <https://github.com/EnverShala/vizpatch-public/security/advisories/new>
2. Alternativ per E-Mail an Enver Shala, envershala1989@gmail.com.
3. Bitte **keine öffentlichen Issues** für Sicherheitslücken eröffnen.

Hilfreich sind: betroffene Datei oder Komponente, Schritte zur Reproduktion und die erwartete Auswirkung.

## Geltungsbereich

Gemeint ist der Code in diesem Repo. Installationen bei Kunden sind nicht Teil dieses Programms. Es gibt keine Zusagen zu Antwortfristen.
