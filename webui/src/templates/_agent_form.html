Vorlagen (vorlagen.md)

Wiederkehrende Formulierungen, die der Chat-Agent auf Zuruf verwenden kann („antworte wie immer bei Terminanfragen"). Eine Vorlage je Abschnitt, Überschrift mit zwei Rauten — der Name in der Überschrift ist der Name, unter dem du sie ansprichst. Der Agent nimmt sie als Ausgangspunkt und passt sie an den Fall an, er sendet sie nicht wörtlich.

Automatische Entwürfe

Ist dies deaktiviert, klassifiziert der Agent eingehende Mails weiterhin, erzeugt aber KEINE Antwort-Entwürfe im Drafts-Ordner. Nützlich für Postfächer, die nur beobachtet werden sollen (spart zudem den teuren Draft-Aufruf beim KI-Anbieter).

Intelligenz-Modus

Wie genau der Agent hinsieht. Wirkt auf drei Dinge: das Erkennen, ob eine Mail eine Kundenanfrage ist; das automatische Einsortieren; und den Filter, der im Urlaub Automatenpost von echten Menschen unterscheidet. Zusätzlich werden die Antwort-Entwürfe mit dem stärksten verfügbaren Modell geschrieben.

„Hoch" verbraucht mehr Tokens und kostet damit mehr beim KI-Anbieter. Bei einem einzelnen Postfach sind das üblicherweise Cent-Beträge im Monat, bei sehr viel Mailverkehr entsprechend mehr. Der Modus ändert nicht, ob überhaupt gesendet, sortiert oder geantwortet wird — das entscheiden weiterhin die Schalter darüber und darunter.

{# Verborgener Marker wie in den Sections oberhalb: ein Select sendet zwar immer einen Wert, aber der Marker hält das Muster einheitlich und macht sichtbar, welche Section abgeschickt wurde. #}
Automatisches Einsortieren

Sortiert bereits GELESENE Mails inhaltlich nach den unten genannten Kategorien ein — oder markiert sie als wichtig, wenn sie liegen bleiben sollen. Ungelesene Mails bleiben davon IMMER unangetastet im Posteingang, bis du sie gesehen hast. Jede Aktion landet im Aktions-Journal und ist über den Chat rückgängig zu machen bzw. nachzuvollziehen ("was hast du heute automatisch weggeräumt?").

Je Kategorie eine Überschrift mit zwei Rauten, darunter Aktion: verschieben (braucht ein Ziel:) oder Aktion: markieren (hebt die Mail im Posteingang hervor, bewegt nichts).

Urlaubs-Autoantwort

Die einzige Funktion, die selbstständig Mails VERSCHICKT. Alles andere im Produkt legt nur Entwürfe an. Im eingetragenen Zeitraum antwortet der Agent auf neue Mails automatisch mit dem Abschnitt ## Urlaub aus den Vorlagen oben — jedem Absender genau EINMAL pro Urlaub, nie an Newsletter, Automaten oder No-Reply-Adressen, und nie auf Mails, in denen dein Postfach nur im Kopie-Feld steht.

Fehlt der Abschnitt ## Urlaub in den Vorlagen, wird NICHTS gesendet — es wird kein Ersatztext erfunden.
